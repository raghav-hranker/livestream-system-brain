- 40 source placements (17 videos) have a CourseClass row with status 0 or isActive false; 19 are in enabled LMS courses. These classes usually retain an HLS reference, but the course placement may hide them.
- 965 active APX video rows have no current video link. Some map to captured LMS classes; they are excluded from the 49 because this audit cannot establish that APX currently offers a video for them.

## Ingest state of the 22 Classes without a playback reference

All 22 have an ingest job: **21 skipped, one pending**. Stored error details group into 17 ffmpeg encoding failures, two decrypt failures, one token mint failure, and one empty player URL. One skipped job has no stored error; the pending job retains the token mint error from an earlier attempt. These states explain why an LMS video reference is absent; they do not by themselves establish whether APX playback currently succeeds.

## Coverage and method

Read-only comparison of 116/116 APX courses, 36,315 source rows across 146 listing pages. 32,847 active VIDEO or LIVE_STREAM rows were considered; 31,882 carried a nonempty link. Row types observed: VIDEO 4,656, LIVE_STREAM 29,272, PDF 2,387. Zero course listing failures.

Videos were matched by the deployed `deriveApxAssetKey` rule. For a live row whose key did not match, the same source row ID in the captured APX course supplied a fallback video identity. A course placement counted as enabled only when `CourseClass.isActive !== false` and `CourseClass.status !== 0`; Class.status and LMS Course.status were checked separately. YouTube redirects, MP4 and legacy links were kept as alternative paths; no qualifying Class in this snapshot used those paths. Neither signed HLS URLs nor file bytes, entitlements, customer UI rendering, or APX watch pages were tested.
