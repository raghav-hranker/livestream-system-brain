# 06 Duplicate from the Assign Classes row ⋯

**Type**: AFK
**Blocked by**: 04
**Feature**: B

## What to build

"Duplicate…" goes last in the outline row ⋯, after Rename… if that exists by merge time. It opens the same
Duplicate dialog as the Classes page for the row's class, using the same next-title helper and course list.
The current course is in the list because the original is placed here. After create, the outline
refreshes and the new row is visible right after the original.

## Acceptance criteria

- [ ] The dialog opened from the row is the same component as the Classes page's. No fork.
- [ ] After create, the new row appears right after the original in this course's outline.
- [ ] Suites print NO NEW FAILURES.
