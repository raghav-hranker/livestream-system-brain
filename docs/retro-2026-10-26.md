## Findings, ranked

1. **Multi-day sessions carry 77 % of the cost.** Four sessions (certificates a6b9b321 396 M, course exchange
   30b3fad7 318 M, feedback 80463e7b 233 M, ops bot b078b029 177 M) ran 3–6 days with no compaction (`opus[1m]`)
   and reached 560–720 k context; the certificates session averaged 447 k per turn across 887 turns. Each new
   question about invoices, my-courses fields or app-team curls was asked inside them. Fix: compact earlier
   (`CLAUDE_CODE_AUTO_COMPACT_WINDOW` in `~/.claude/settings.json` env) and one session per phase (design →
   PRD/tasks → build → deploy/app-team Q&A); the PRD and task files already hold the state, `/handoff` exists.
2. **Task waves still wait for "yes, start task N" (10-20 finding #1, not applied).** "Start task 03 the same
   way", "04 and 05 in parallel", "05 and 06", "07". 30b3fad7: hand-back 08:39, go 09:35. Fix: a `/build
   <task-folder>` skill (or rule in `docs/agents/issue-tracker.md`) that runs every unblocked task after one
   approval, stopping only for HITL tasks or `NEW FAILURES`.
3. **Replies too dense: 19 `/bro`.** Replies just before `/bro` had median 2.5 k chars vs 1.6 k overall, mostly
   tables. Fix: a default output style that leads with the `/bro` version (plain, short) and offers detail.
4. **Auto-mode denials (backlog #5, open since 10-19).** Production Reads ×8, Production Deploy ×3, no-reason ×4,
   deletion/PII/shared ×3. Two sessions (5cb467ed, 51ad0ccc) existed mostly to say "yes, run it". Fix:
   `autoMode.environment` (owned boxes from `reference/hosts.md`, read-only probes in `reference/scripts/` are
   routine) and `autoMode.allow` for those probes and the deploy script below.
5. **Vidyagram deploy recipe typed every time (backlog #7).** "Back up dist, merge onto vidyagram-admin, surgical
   dist, push, pull, pm2 92, smoke-check" ~7 times in 2 days, each many ssh calls and the three deploy denials.
   Fix: `scripts/vg-deploy.sh <commit> [--check|--apply]` wrapping `qt-surgical-dist.sh`, backup, ff, restart, smoke.
6. **Recurring checks by hand.** 5ef14e6a "any 695 stuck / any more new today": 20+ prompts over 16 days, 65 M
   tokens. ccef10b7: the ops bot's stranded-VOD triage pasted into Claude to fix. Fix: stuck-class check for 695/561
   in the 08:30 digest plus an ops-console Act "recover VOD" (qt-vod-recover.cjs).
7. **Big one-shot reads riding long sessions.** `visualize` read_me 63 k chars (~16 k tokens) ×7, in four long
   sessions; Artifact quickstart 37 k ×3; poteto-mode SKILL.md 25.6 k + playbooks 20 k (109 loads in 14 days).
   Fix: diagrams, artifacts and explainers go to a side session (you already do "explain in a new chat").
8. **App-team relay.** Pasted team asks, "what shall I say to the mobile dev", "give me a curl with his token",
   "mark this course complete so they can test". You are the app team's test desk. Fix: a self-serve test kit per
   feature (guide + test student + sample curls + the admin action), handed over with the guide.
9. **Static baseline ~90 k/turn ≈ 14 % of cache reads.** Tools 32 k (Artifact 9.5 k, Browser 5.6 k, iOS
   Simulator 1.6 k), skill listing 7.6 k, MCP instructions + deferred names 5.4 k, agents 1.9 k, MEMORY.md 4.7 k.
   Unused in 14 days: Figma, Hugging Face, job-search connectors (0 calls); Vercel plugin (5 skill loads). Removing
   them and trimming MEMORY.md hooks saves ~5 k/turn.
10. **Disk: 306 worktrees, 42 GB, disk 89 % full** (backend 188, admin 136; 109 + 66 on 10-19). `qt-tasks.sh rmwt`
    exists; prune merged ones.
11. **Secret in a transcript.** An Anthropic API key was pasted into b078b029 (ops bot setup) and sits in plain
    text under `~/.claude/projects/`. Rotate it; put keys on the box with a hidden prompt (`read -s`), never in chat.

## Product friction (where you got stuck)

- Third-party dashboards (Kuma/Telegram token and chat id, Cloudflare R2 token, noindex rule, ticket text) became
  "give me a prompt for my other agent". Claude in Chrome can drive a dashboard you're signed in to; the `wizard`
  skill covers steps only you can do.
- Brainstorms drift ("the discussion has started to become incoherent", 35924175). Numbered-question grilling
  (Q1–Q21 in a6b9b321) converged; open-ended chat didn't. Ask for the decision table first.
- 380 uncommitted paths in system-brain (backlog #3).
