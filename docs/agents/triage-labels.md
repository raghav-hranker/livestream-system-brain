# Triage labels

| Canonical role | Local workflow state | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the work. |
| `needs-info` | `needs-info` | Waiting for missing product or technical information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and executable without additional context. |
| `ready-for-human` | `ready-for-human` | Requires human implementation or coordination. |
| `wontfix` | `wontfix` | Will not be actioned. |

Record one of these values near the top of a PRD or implementation task when workflow state is needed.
