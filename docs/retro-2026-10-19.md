## 5. qt-health runs at wake time, not 08:30, and had a silent partial run
Plist says 08:30; actual runs: 14:06, 13:56, 15:54, 11:16, 11:15. launchd coalesces a missed `StartCalendarInterval` to the next wake, so "this morning's run" in CLAUDE.md is usually an afternoon run from yesterday's data. The 10-18 run died on `ssh exit 255` with no retry; its verdict line is correct but nobody saw it.
**Fix:** retry the ssh block once after 30 s; print the run timestamp in the verdict line; reword the CLAUDE.md pointer to "latest run"; optionally add a second interval at 13:00 so a sleeping laptop still gets a same-day run.
