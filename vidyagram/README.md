# Vidyagram (customer 781)

Everything in this folder is Vidyagram-only. Tenant facts (branches, DB, boxes, domains, deploy) are in
[`../TENANTS.md`](../TENANTS.md). Logins are in [`../reference/hosts.md`](../reference/hosts.md). Scripts stay in
[`../reference/scripts/`](../reference/scripts/) with a `vidyagram-` prefix.

- `plans/` holds PRDs and task folders: onboarding (`appx-tenant-onboarding`), Course Builder, catalogue filters.
- `reports/` holds dated investigation and setup reports.
- `reference/` holds the app-team API guides and the Postman collection.

Nothing here ships to quicktricks. A bug found in shared fork code is reported for quicktricks separately.
