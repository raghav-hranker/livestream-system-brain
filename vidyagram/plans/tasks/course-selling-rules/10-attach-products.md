# Attach products

**Type**: AFK
**Blocked by**: 03
**Repo**: Backend + admin

## What to build

The Attach products row on the Content step: courses, test series and books. They write to the main plan's lists, and a student simply gets access with nothing extra on the course page. Additions reach past buyers. Removals warn.

## Acceptance criteria

- [ ] A buyer can open an attached course, test series and book.
- [ ] A past buyer gets an addition.
- [ ] The course page's data shows nothing extra for attached products.
- [ ] A removal shows the warning with the order count.
- [ ] Attached courses are never listed as sub courses.
- [ ] `NO NEW FAILURES` against the baselines.
