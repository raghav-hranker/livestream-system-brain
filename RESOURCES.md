# Cookie Authentication Resources

## Knowledge

- [IETF RFC 6265: HTTP State Management Mechanism](https://datatracker.ietf.org/doc/html/rfc6265.html)
  The protocol definition for `Cookie` and `Set-Cookie`. Use for: exact browser/server responsibilities and cookie replacement rules.
- [MDN: Using HTTP cookies](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Cookies)
  Clear operational guide to cookie storage, scope, expiration, and security. Use for: browser behaviour and practical examples.
- [MDN: `Set-Cookie` header](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie)
  Attribute-level reference for `Domain`, `Path`, `Expires`, `Max-Age`, `Secure`, `HttpOnly`, and `SameSite`.
- [OWASP Session Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)
  Security guidance for session IDs, rotation, expiry, invalidation, and lifecycle logging. Use for: designing the permanent APX fix.

## Wisdom (Communities)

- [OWASP Community](https://owasp.org/chapters/)
  Practitioner community for reviewing authentication and session-management designs when a future change needs external security scrutiny.
